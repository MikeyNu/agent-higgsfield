# Seedream
Checked 2026-10-18. Keep 4.5, 5.0 Lite, 5.0 Pro and 5.0 Flash distinct. Resolve the exact version and current mode.

## Direct the image
For documented 4.0/4.5/5.0 Lite workflows, use concise natural language: subject, action and environment, then relevant style, color, light and composition. Explicitly assign what comes from each input image. For sketch-to-render, identify the requested deliverable and which spatial relationships must match.

For a localized edit, name the object, its location and the intended change; list surrounding properties that must remain. Pro's spatial-grounding claims support testing this approach, not promising pixel-perfect preservation. Do not apply an older version's advanced syntax to a new version without checking its guide.

## Surface checks
The live snapshot gives Pro/Flash resolution choices of 1k/1.5k/2k, while 4.5/Lite expose basic/high quality. The public Pro page contains conflicting 2K and 4K wording. Prefer current task settings and verify output dimensions.

Pro exposes is_inpaint for reference editing but no mask media role in the snapshot. Do not submit a mask merely because the mode is named inpaint. Search/reasoning marketing does not establish a user-controllable connector parameter.

## Original example
"Use reference 1 as the room layout and reference 2 only as the material sample. Render the room with the same camera position, opening shapes and object placement. Replace the floor material with the pale terrazzo from reference 2. Keep the walls, daylight direction and three black sculptures unchanged."

## Failure gates
Inspect geometry, material boundaries, labels, reflections and changes outside the requested region. Compare against the input rather than judging attractiveness alone. Use measured geometry or deterministic artwork when exactness is mandatory. Promote a candidate to a video keyframe only after this check.
