# Inspect and repair

Judge the acceptance contract, not merely visual appeal. Do not turn every preference into an expensive retry.

## Minimum evidence

For images, inspect the full composition and detail at intended delivery size. For video, watch the entire clip at normal speed, then inspect opening, ending, transitions and risky action frame by frame. A contact sheet cannot establish smooth motion, correct speech or absence of a one-frame defect. Check sound separately. Record any uninspected portion.

Check: subject and reference fidelity; geometry and object count; hands, faces and contact; camera direction and endpoints; unintended cuts; lighting; text/logos; audio sync; requested duration, ratio, resolution and delivery format. Inspect joins and loops in motion. Confirm the actual file decodes; do not infer native resolution from a filename or label.

## Diagnose before buying another attempt

| Defect | First targeted response |
| --- | --- |
| Identity or product drift | Improve the source/reference role; reduce transformation; use supported edit or stronger control |
| Wrong camera move | Remove contradictory cues; use exposed motion controls or a driving blockout |
| Topology/architecture mutates | Reduce the move or use deterministic geometry; more adjectives will not fix the world model |
| Timing or cuts wrong | Simplify the event; use true shot controls or edit separate accepted shots |
| Exact text/logo wrong | Composite source artwork or live typography; do not burn retries on letter perfection |
| Local object/hand defect | Isolate a supported edit or replace only the affected shot |
| Reference not followed | Verify role, crop, input confirmation and whether the mode accepts that reference |
| Flicker or unstable detail | Reduce high-frequency complexity/motion; inspect source and alternate method; do not assume upscaling repairs it |
| Lip sync/dialogue wrong | Verify actual audio timing, speaker assignment and supported lipsync route |
| Crop/grade/length wrong, content usable | Reframe, grade or trim with the editor |
| Timeout or missing widget | Recover existing job; do not generate again |

A revision needs a hypothesis, one meaningful change and a remaining allocation. Keep accepted outputs. If the same material defect persists, change the method or stop instead of repeating equivalent requests. Escalate only after making the revised proposal and cost concrete.

## Honest delivery record

```text
Status: confirmed complete / pending / failed / outcome unknown
Output and source version:
Checks performed:
Acceptance passed / deviations:
Actual charged credits, or reserved/quoted if unresolved:
Attempts and remaining authorized budget:
Next action, if needed:
```

Offline prompt reviews and unit tests validate process rules only. They do not measure model success rates, visual fidelity, provider charges or the quality of a generated video. Do not call a skill generation-tested without inspecting real authorized outputs.
