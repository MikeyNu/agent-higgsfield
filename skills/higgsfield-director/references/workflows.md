# Specialist workflows

Resolve the current named recipe before execution. A workflow is not a model ID. Follow the current tool contract and input schema, including required integrations and approval gates. Browsing does not authorize a run.

## Cinema Studio and camera direction

Inspect the active Studio version and exposed camera, lens, light, tempo and reference controls. Establish a clean keyframe and align prose with the selected controls. Use a continuous/single-shot mode for a continuous camera journey when available. A camera preset can improve direction but is not a deterministic simulation or proof of a fixed trajectory.

Keep Higgsfield DoP, a Cinema Studio director panel, Kling Motion Control and the phrase “Motion Director” distinct. The last phrase did not resolve to a specific recipe in the research snapshot. Discover the actual surface or ask for the relevant link/screenshot after useful lookup; do not invent a model.

## Genjutsu

Resolve the current intent: transfer motion, replace an object/subject, or apply a named style. A driving video carries movement/timing; images supply the replacement or appearance. Confirm both kinds of input when the route requires them. A video-only quote is not evidence that the recreation is ready.

Inspect reference duration, framing, visible limbs, camera cuts and occlusions before spending. Describe the requested change and what remains. Use the actual returned model or style ID, never a catalog ID as a model. For a style, use its exact input schema. Reuse `prepared_params` after estimation to avoid duplicate imports.

## Katana / Video Editor

Resolve `/use-video-editor` first for editor work. For a named preset, read its exact recipe and required source/reference inputs. Inspect the existing footage before deciding to generate missing material. Preserve shot order, timing and source media; prepare an edit decision list for cuts, crop, sound and overlays.

A named Katana run can require a preset session even when free. Starting that session mutates state and is not needed for research. Pass the real returned session ID as the recipe requires, including estimates. Free-generation requests need explicit user intent and verified eligibility; never retry a rejected free request on credits automatically.

If the required local editor plugin is unavailable, explain that specific limitation. Do not replace it with an unrelated cloud sandbox or fetch and execute external scripts. Register/display only a verified final result from the actual supported workflow.

## Three separate Blender routes

| Route | Verify before work |
| --- | --- |
| Cloud 3D Jutsu | Existing project/revision, scene sequence and active operation. Inspect before a revision-guarded edit. Preserve committed .blend/GLB masters. |
| Desktop Blender add-on / Bridge | Actual installed integration, saved scene and connection. Cloud AI finishing uses separate account operations. |
| `/use-blender` local MCP | Required local plugin/runtime and its scene. A background Blender process does not imply access to unsaved work in the user's open app. |

Do not call a local render free without checking its execution surface and charges. Preview topology, camera clearance, silhouettes, scale, lighting and the full path before AI finishing. A paid image/video call inside a 3D workspace is still a paid generation and needs budget preflight. Do not overwrite an existing scene or ignore a revision conflict.

For a scroll journey, use explicit camera keyframes/splines for the rigid world. Keep website typography in HTML or deterministic composition. Test geometry at intermediate poses, not just endpoints. AI stylization of a blockout may still alter shape, motion or light. Preserve the deterministic version as a fallback.

## Other tools

For masks, background removal, upscaling, reframe, lipsync, voice, ads, training, Canvas, batch or future tools: inspect whether the action reads, uploads, mutates, generates, publishes or deletes. Apply budget gates to every potentially charged action, not only `generate_video`. Keep account preferences and public sharing unchanged unless requested. Do not present generative enhancement as recovery of factual detail.

For website builders or other non-media tools, load their actual workflow and preserve the user's scope, source and access settings. Do not apply an image-model prompt to a website operation. The same intent, capability, side-effect and spending checks still apply.
