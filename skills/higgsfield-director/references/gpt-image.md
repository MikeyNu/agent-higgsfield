## Direct the image
- Specify the deliverable and composition before stylistic detail. Separate requested changes from protected identity, geometry, labels, lighting and layout.
- Number references by role: edit target, product, person, style, background. Define how they combine.
- Quote literal copy, its location and typography. Spell unusual names when necessary. Check the final lettering rather than trusting the prompt.
- Reuse the accepted output for a narrow edit and restate its invariants. Inspect surrounding content for unintended changes.
- Use Flare versus Sunburst only when the resolved GPT Image 2.5 route exposes that choice. Their provider positioning is speed versus quality, not a guaranteed cost ranking for every Higgsfield request.

## Failure gates
Typography, repeated identity and exact composition remain probabilistic. If the logo or essential text drifts, preserve the usable scene and composite approved artwork or perform a supported local correction. Use deterministic layout for exact coordinates, factual diagrams and final interface text. Verify an unfamiliar version on the task's actual failure risks before adopting older prompting habits.
