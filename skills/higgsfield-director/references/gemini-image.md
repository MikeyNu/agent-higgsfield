## Direct the image
Describe the intended asset, subject, environment and concrete visual decisions in connected language. Assign each reference a role. For complicated scenes, describe a few construction steps. For revisions, use the accepted image and request one visible change with protected details stated again. Supply a pose reference for a difficult pose, and accepted views when generating another angle of the same character. Draft exact wording before asking the model to render it.

Google's guidance supports specific composition and photographic language. Long adjective lists add less control than explicit subject relationships.
