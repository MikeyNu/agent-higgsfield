# Audio, lip sync and 3D assets

These are discovery-driven adapters, not claims that every provider control is exposed. Inspect the current selected tool/model and price; some tools are standalone operations rather than catalog generation models.

## Speech and audio

Resolve a real voice ID from the available voice list. Preserve the exact script, language, pronunciation needs, speaker count, pace and target duration. Do not invent a voice ID or assume an audio model shares a video model's reference syntax. Obtain permission for the supplied voice/person where needed; do not infer cloning authorization from a generic voiceover request.

Keep speech, ambience, music and sound effects distinct. Use the model's supported tags and settings only. For dialogue, assign each line to a speaker and provide enough time. Review intelligibility, pronunciation, pauses, clipping, loudness and alignment with the picture. If timing is exact, edit or record the source rather than rely on a prompt's second count.

Original direction: “A calm South African English delivery, conversational and unhurried. Read the supplied script exactly. Pause briefly after the first sentence.” This requests a delivery style, not a guaranteed accent or duration.

For lipsync or voice replacement, inspect the source audio/video, duration and speaker visibility first. Preserve source footage when the goal is only sound. Preview mouth synchronization through the clip, not only on its opening frame.

## Image/text-to-3D

Identify whether the task is object generation, multiview reconstruction, rigging, remeshing, retexturing or deterministic scene editing. Use compatible views of the same object with consistent perspective and proportions; do not pass unrelated images as multiview geometry.

Inspect topology, backside plausibility, scale, materials, UVs, mesh count, rig and intended export format. A plausible front render does not prove a usable asset. Generative reconstruction cannot establish unseen geometry as factual. Use Blender/CAD for exact dimensions and logo silhouettes.

Original object brief: “A single freestanding three-fin sculpture, three separate solid pieces, consistent thickness, matte-black finish. No floor or surrounding room in the asset.” Assign dimensions and placement in a deterministic scene if they are requirements.

## Unknown utility or future model

Read the exact input/output contract, required assets, side effects, quote method and result-status path. Preserve the original and inspect an actual output before adopting it. If no authoritative price or bounded charge is available, prepare the operation and ask for a supported budget decision; do not spend to discover its price.

Evidence: current Higgsfield `models_list`, `models_get`, `list_voices`, standalone tool descriptions and Blender/3D Jutsu routes. No paid audio or 3D quality benchmark was conducted for this skill.
