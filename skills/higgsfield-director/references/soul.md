# Higgsfield Soul
Checked 2026-10-18. Distinguish Soul, Soul 2.0, Soul Cinema, Soul Cinema Studio, Soul Cast and Soul Location.

## Choose and direct
Use Soul 2.0 for an editorial/fashion direction with a coherent preset or Moodboard. Use Soul Cinema when a cinematic still is the intended aesthetic. Describe the scene, wardrobe, motivated lighting and mood without contradictory styles.

Match the preset's treatment to the brief. A fashion/beauty finish can conflict with observational realism. Prefer a restrained, task-directed moment and context-appropriate skin/fabric detail over compulsory blemishes or grain. Cinema's marketed realism is not audience-test evidence. Do not add a paid skin enhancer or face restoration unless inspection identifies a suitable defect and spending is authorized.

Resolve a requested trained identity first. A Soul ID is not a reference Element or an arbitrary asset ID. Do not silently drop or replace an unavailable identity. Describe scene changes while protecting the accepted person's appearance; verify consistency after generation.

## Surface checks
The web Help Center says an attached reference disables the text prompt in Soul 2.0 and Soul Cinema. Inspect the active surface instead of assuming web and MCP behavior match.

The live Soul 2.0 schema allows style_id with soul_id but disallows style_id with image references. Soul Cinema's web surface has no Moodboard or preset panel. Soul Cinema Studio is a separate model with different controls. Soul Cast and Soul Location are text-only entries in the snapshot. Do not pass reference images to them without new schema evidence.

## Original example
"An editorial photograph of the selected character in a Johannesburg design studio. A white cotton shirt, relaxed stance beside a worktable, natural window light from camera left, restrained black-and-white surroundings and believable fabric texture. The composition catches a quiet working moment rather than a staged corporate handshake."

Set the trained identity through the supported identity control, not merely its name in prose.

## Failure gates
Check likeness, anatomy, clothing, texture and cultural context. A nationality cannot be established from facial appearance alone; communicate setting and casting intent respectfully. A pleasing portrait does not prove identity preservation. Save an approved character/location before using it as a video reference.
