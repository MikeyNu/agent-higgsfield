# Other image models and utilities
Checked 2026-10-18. Choose the requested operation first. Use live capability discovery for any unfamiliar model/version: exact ID, mode, required inputs, supported parameters, output type and current provider guidance. Do not manufacture a prompting dialect from its name.

## Routes
- **Ideogram:** use exact copy and typography requirements. The provider's 4.0 guide distinguishes natural language with Magic Prompt from structured JSON with it off. Do not assume the same schema applies to Higgsfield's 4.5 entry. Inspect the active version before using JSON fields. Check whether enhancement may reinterpret a tightly constrained brief.
- **Recraft:** distinguish raster output from native vector mode. Specify medium, visual hierarchy and palette use. Verify the returned file really contains editable paths when SVG is required; a raster embedded in SVG is insufficient. Current Higgsfield entries include vector model types and palette controls, but no image-reference role in the sampled Recraft schemas.
- **Kling O1 Image, Grok Image and Z Image:** use a concise scene/reference brief compatible with the discovered version. Higgsfield describes Z Image as fast stylized generation; its sampled schema is text-only. No unsupported identity, precision or speed guarantee follows from catalog descriptions.
- **Marketing/DTC image tools:** resolve required style, brand kit and product inputs through their dedicated workflow. A style picker or research action does not authorize image generation. Do not substitute a general model for a named workflow silently.
- **Background removal, outpaint, decompose and upscaling:** use their operation-specific inputs instead of a full scene-regeneration prompt. For expansion, identify what continues beyond each edge. For restoration, inspect any newly invented lettering, faces or texture; added detail is not recovered truth.
- **Sprite animation:** confirm frame dimensions/count, motion cycle, transparency and atlas needs before generation. Inspect frame alignment and loop seam.
- **Auto routing:** use only when compatible with the user's control requirements; record the actual resolved model if returned. Do not treat an unresolved Auto choice as a validated model-specific plan.

## Original example
For a verified vector route: "A small monochrome icon of three separated architectural fins, simple closed shapes, broad negative spaces, suitable for a 24-pixel interface. Black fills on a transparent canvas." This creates a concept; reuse approved Nu Labs logo artwork when identity must be exact.

Inspect spelling, geometry, palette, alpha channel and editability at the intended size. If the request needs exact text or known geometry, prefer native layout/compositing.
